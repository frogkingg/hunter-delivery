# 智能填充使用说明（v1.3.0）

智能填充是「猎投」的新增主功能：在第三方公司网申页面的信息录入页面，自动识别输入框、下拉框、单选框、复选框、文本域等表单项，结合你的简历内容自动匹配并一键填充，大幅减少招聘季海投时的重复填写。

## 一、工作原理

1. **扫描**：在网申页面点击「扫描当前页面」，插件识别页面上所有可填写的表单项（原生控件 + 常见组件库自定义控件，如 Ant Design / Element）。
2. **匹配**：识别结果与你的简历字段进行匹配，优先级为：站点模板记忆 > 本地规则 > AI 匹配（可选）。
3. **预览修改**：侧边栏逐项展示匹配结果，可编辑建议值、勾选要填充的项。
4. **填充**：一键执行填充，逐字段回报进度；失败项在页面高亮，手动补齐即可。
5. **记忆**：同站点第二次扫描时自动复用上次的填充与修正（站点模板）；每次填充记录到历史。

## 二、前置准备

1. 在「设置」中配置 AI API（可选，仅复杂字段匹配与简历字段提取需要）。
2. 在「设置 → 我的简历」中上传/粘贴简历内容，并在「智能填充 → 简历字段」中点击「重新提取简历字段」生成结构化字段；提取后可手动修正。
3. 打开目标公司的网申 / 信息录入页面（非 BOSS 直聘）。

## 三、操作步骤

1. 打开网申页面 → 切换到侧边栏「智能填充」标签页。
2. 确认顶部选择的简历正确。
3. 点击「扫描当前页面」：
   - 首次使用会弹出该网站的访问授权，请点击允许；
   - 扫描完成后列表展示识别到的表单项与匹配建议。
4. 检查匹配结果：
   - 绿色「置信高 / 中」且来源为「规则 / 模板 / AI」的项会默认勾选；
   - 灰色「需手动」项无法自动填充（如密码、文件上传、无法确定的勾选框），请在页面上手动填写；
   - 可直接修改任意行的建议值。
5. 点击「填充选中项」（仅填充勾选项）或「全部填充」。
6. 填充完成后，失败项会在页面高亮；补齐后点击「清空」可移除高亮。

## 四、设置项

| 设置 | 说明 |
|---|---|
| 复杂字段使用 AI 匹配 | 未识别/低置信字段批量发送给你配置的 AI 服务匹配（产生少量 token 费用）；关闭后仅用本地规则。 |
| 自动记忆站点模板 | 同站点（按域名）自动复用上次填充与手动修正；可在「当前站点模板」查看或删除。 |

## 五、支持的控件

- 文本类：`text`、`tel`、`email`、`number`、`url`、`textarea`
- 选择类：原生 `select`、radio 单选组、checkbox 勾选（仅明确布尔值时自动勾选）
- 日期类：`date` 原生控件、`.ant-picker` / `.el-date-editor` 自定义日期
- 自定义下拉：`.ant-select` / `.el-select`（点击选项或回退到输入框赋值）
- 不填充：密码、文件上传、隐藏控件（标记「需手动」）

## 六、常见问题

**为什么扫描不到表单项？**
页面表单可能为异步渲染或使用了 iframe / Shadow DOM，请等待页面加载完成后再扫描；v1 不支持 iframe 内部表单。

**为什么某字段显示「需手动」？**
简历中缺少对应信息（如身份证号）、控件类型无法自动填充（密码/文件）、或勾选框语义不明确。属预期行为，页面上手动处理即可。

**AI 匹配失败会影响填充吗？**
不会。AI 仅补全未识别字段，失败时自动降级，其余字段正常填充。

**隐私说明**
开启 AI 匹配时，「表单字段标签 + 简历字段」会发送到你配置的 AI 服务；简历图片与全文不会因智能填充被发送。站点授权、模板与日志均保存在本机 Chrome 扩展存储中。
