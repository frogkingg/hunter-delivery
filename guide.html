猎投

从岗位分析到确认投递

首次：配置 AI → 创建简历 → 上传解析；日常：分析岗位或加入清单 → 生成招呼语 → 确认投递。

01

配置 AI + 创建简历

在「设置」中填写 API 地址、模型和 Key，点击"测试连接"。DeepSeek 用户建议保持"关闭思考模式"开启，以减少等待时间。最多可创建 5 份简历，每份独立管理内容、图片和写作要求。

02

上传并解析简历

上传 JPG 或 PNG 简历图片，AI 会流式提取经历、项目、技能和量化成果。请检查并保存提取结果；生成招呼语时使用简历文字，实际投递时发送已保存的简历图片。

03

分析当前岗位

打开 BOSS 职位列表或详情页，点击"分析当前岗位"。插件会流式生成 JD 匹配分析和 3 种招呼语风格；选择或编辑后，再点击"确认沟通并发送"。

04

建立投递清单

浏览岗位时点击"加入投递清单"，最多保留 20 个待处理岗位。批量生成时，每个岗位保存 1 条可编辑招呼语，并绑定当时使用的简历。

05

批量生成招呼语

在投递清单点击"批量生成招呼语"。页面会显示当前岗位、耗时和接收字符数；生成后可展开卡片检查岗位、绑定简历和招呼语，并直接修改保存。

06

开始投递与失败恢复

点击"开始投递"后，插件逐项打开详情，按岗位 ID 和标题核验目标，再处理正常沟通弹层、发送简历图片和招呼语。连续 3 次失败会自动停止。普通失败项可展开并点击"保存修改"恢复待投递；"已发送待归档"不可重发。

发送前请确认岗位、招呼语和绑定简历。 正常的"已向 BOSS 发送消息 / 继续沟通"弹层会自动处理；验证码、滑块、安全验证、访问异常或操作限制不会自动绕过，请手动完成后再重试。服务商返回 usage 时，当前岗位分析会显示 Token 用量和费用估算。
