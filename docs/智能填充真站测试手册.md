# 智能填充真站测试手册（v1.4.0）

本手册用于在**真实网申平台**上人工验证智能填充功能。自动化测试（单元 + 夹具）已覆盖基础能力，真站验证用于确认真实环境兼容性并收集问题。**请至少在 5 个不同公司的网申页面完成一轮测试**，并将结果按文末表格反馈。

## 测试前准备

1. 安装 v1.4.0 版扩展（加载已解压的扩展程序方式）。
2. 在「设置」配置 AI API（可选，推荐开启，便于验证 AI 匹配路径）。
3. 准备一份包含以下信息的简历内容并提取简历字段：
   姓名、手机号、邮箱、性别、出生日期、毕业院校、学历、专业、毕业时间、工作年限、现居城市、期望薪资、自我评价、到岗时间。
4. 准备 5 个以上不同公司（不同网申系统）的账号/可访问链接。

## 测试步骤（每个站点）

1. 打开该公司的网申 / 信息录入页面，等待页面完全加载。
2. 侧边栏切到「智能填充」→ 确认简历 → 点击「一键智能填充」。
3. 记录：识别到的表单项数量、是否与页面实际表单控件一致。
4. 若页面存在经历区块且简历有条目，一键流程会自动展开并重扫（页面只新增到简历所需条目数，无需手动点击）；展开失败只提示、不中断填充。
5. 检查匹配列表：常见字段（姓名/手机/邮箱等）是否正确匹配；对「需人工处理」项选择字段或补录值，勾选后点击列表下方的「填充勾选项（N）」补填。
6. 逐字段核对页面实际值：
   - 文本类：值是否正确；
   - 下拉类：是否选中正确选项（选项集不匹配时是否明确报「选项未找到」）；
   - 复合手机号：区号与号码是否分别写入正确 slot；
   - 日期范围：开始/结束时间是否绑定同一条简历经历；
   - 单选/勾选：是否正确选择；
   - 失败项是否在页面高亮。
7. 手动修正任意一项并再次扫描（同站点），确认 Template V2 复用的是字段映射；切换另一份简历后应使用新简历的值，不能复用旧姓名/手机号。
8. 扫描后让页面新增/删除一个表单项或进入下一步，再尝试填充；旧会话应停止并提示重新扫描，不应写入其他字段。
9. 记录填充时长、页面是否卡顿、是否有页面报错。

## 验收口径

- 识别率 ≥90%（识别数 / 控件总数）；
- 常见字段（姓名、电话、邮箱等）匹配准确率 ≥95%；
- 总体匹配准确率 ≥85%；
- 填充过程流畅（无明显卡顿），失败项可定位（高亮）。

## 问题反馈注意事项

- 请附上：站点域名、页面 URL（脱敏）、出现问题的表单项标签、期望值与实际值、控制台报错（如有）。
- 敏感信息（身份证号、手机号）请打码后反馈。
- 无法自动绕过的验证码、滑块、登录墙不属于缺陷，无需反馈。

## P1 新功能真站用例（v1.4.0 起）

> 覆盖：一键智能填充 / 点击字段填充 / 增量续填。至少各测 1 个原生表单 + 1 个 Ant Design 表单。

### 一键智能填充（自动模式默认开启）
1. 打开网申页 → 侧边栏「智能填充」→ 点击「一键智能填充」主按钮。
2. 预期：自动完成 扫描 →（如需）自动展开经历并重扫 → 识别 → 勾选高置信项 → 填充；toast 显示「一键填充完成：成功 X/Y」。
3. 校验：姓名/手机号/邮箱等已匹配字段被填入；列表折叠为「需人工处理 N 项」+「已自动填充 N 项」，「需手动」项未被填入且留在「需人工处理」区。
4. 关闭「自动填充高置信项」开关后再次点击「一键智能填充」：只扫描不填充，列表展示全量字段，勾选后点击「填充勾选项（N）」补填。

### 点击字段填充
1. 扫描后进入「简历资料」编辑器，任选一个有值的标量字段（如姓名），点击「填入页面」。
2. 预期：页面进入拾取态（顶部提示「点击要填入的位置（Esc 取消）」），鼠标悬停输入框有蓝色描边。
3. 点击页面目标输入框：该字段值被填入并回读；toast 显示「已填入「…」」。
4. 点击非输入框区域：出现「请点击输入框/下拉框」提示且不写入、拾取态保持；按 Esc 取消。

### 增量续填
1. 完成一次填充后（填充成功即自动启用监听），在页面手动「新增一条教育/工作经历」。
2. 预期：出现「继续填写（N 个新字段）」按钮。
3. 点击后：仅填充新增字段（已处理字段不被重填），toast 显示「已继续填充」。
4. 再新增一次：可再次续填；累计达到 3 轮后不再提示。

### 敏感字段强制人工（v1.4.0 起）
1. 打开含 身份证号 / 期望薪资 / 紧急联系人 的网申页（如北森），执行「一键智能填充」。
2. 预期：上述字段默认进入「需人工处理」，不被自动填充；在列表显式勾选并点击「填充勾选项」后才填充。

### 失败自动模拟输入重试（v1.4.0 起）
1. 打开含「必须真实输入」校验的受控字段页面（如 Moka 部分控件），执行填充。
2. 预期：标准填充失败后自动以逐字符模拟输入重填；仍失败时面板显示「已尝试模拟输入仍失败，请手动填写」。

### 绿/橙着色与撤销（v1.4.0 起）
1. 一键填充后检查页面：成功字段绿框、待人工字段橙框，与面板图例一致。
2. 点击「撤销本次填充」：已填字段恢复原值、绿橙框全部清除；自定义组件未完全恢复时 toast 提示。

### 选区填充（v1.4.0 起）
1. 点击「选区填充」→ 在页面点击「紧急联系人」容器。
2. 预期：只填充该容器内的字段；点击空白不误填整页。

### 导出诊断包（v1.4.0 起）
1. 填充后点击「导出诊断包」，下载 JSON。
2. 预期：JSON 含 scanId/engineVersion/匹配统计/失败原因；手机号、身份证、邮箱被打码，URL 无 query 参数。
