# 智能填充「一键填充」简化设计规格 — 放心一键（Option A）

> 状态：已批准（2026-08-04）。依据：用户对智能填充按钮过多的反馈 + 头脑风暴确认的 Option A（放心一键）。
> 关联规格：[2026-08-03-smart-fill-design.md](./2026-08-03-smart-fill-design.md)（引擎与协议不变，本规格只改面板 UI 与编排）。

## 1. 背景与问题

「智能填充」页当前有 6 个常驻按钮，容易让用户不知所措：

| 按钮 | 现状问题 |
|---|---|
| 智能填充（主） | 已是一键雏形，但被其它按钮淹没 |
| 扫描当前页面 | 只扫描不填充，已被主按钮包含 |
| 展开简历经历（+N） | 一键链条中缺失的一环——主按钮不会自动展开 |
| 填充选中项（N） | 扫描后默认全勾选，与「全部填充」等价 |
| 全部填充 | 同上，仅用户取消勾选时才有区别 |
| 清空 | 常规重置，可缩小为按需出现 |

目标：**一个主按钮完成"网申填充"全部自动动作**，其它操作按需出现，减少认知负担，同时保持安全（只自动填高置信项，需手动项保留人工确认）。

## 2. 目标与非目标

### 目标

- 顶部按钮区默认只有 1 个主按钮「一键智能填充」。
- 主按钮 = 授权检查 → 扫描 →（按需）自动展开经历并重扫 → 填充高置信项 → 折叠展示结果，只突出需人工处理的项。
- 其它操作（清空、填充勾选项、停止、继续填写）按场景出现，不常驻。

### 非目标（本次范围外）

- 不改匹配引擎、填充执行、指纹/格式/选项校验等引擎逻辑。
- 不改三个配置开关的语义（AI 匹配 / 自动记忆模板 / 自动填充高置信项）。
- 不改站点模板、填充历史、简历资料编辑器、点击字段填充、增量续填。
- 不做"全自动连需手动项也填掉"（那是 Option B，被否决）。
- 不改 manifest 权限与版本号。

## 3. 按钮结构变化

| 现在（6 常驻） | 去向 | 新形态 |
|---|---|---|
| 智能填充 | 升级为主按钮 | 「一键智能填充」 |
| 扫描当前页面 | 删除 | 被主按钮吸收；关闭「自动填充高置信项」= 只扫描预览 |
| 展开简历经历（+N） | 删除按钮 | 自动并入一键流程（按需自动展开并重扫） |
| 全部填充 | 删除 | 扫描后默认全勾选 = 主按钮默认行为 |
| 填充选中项（N） | 下沉 | 移到结果列表底部工具条，仅当有勾选项时出现 |
| 清空 | 缩小 | 扫描结果行尾的细小文字链接，仅扫描后出现 |
| 停止 / 继续填写（N） | 保留 | 仍按需出现（填充中 / 检测到新字段） |

## 4. 一键流程

主按钮「一键智能填充」点击后：

```
授权检查（首次需授权该站点）→ 扫描
  ├─ 页面有经历区块且简历有条目 → 自动展开经历并重扫（失败降级继续）
  ├─ 「自动填充高置信项」开 → 直接填充已匹配项；关 → 停在预览列表
  ├─ 填充中显示进度 + 「停止」
  └─ 完成后：成功项折叠，列表只保留「需人工处理 N 项」
```

细节约定：

- **自动展开经历**：复用现有 `prepareFillSections` 的编排与 `SMART_FILL_PREPARE` 协议（指纹校验、上限 10、逐次验证数量增长）。一键流程中调用它，失败仅 toast 提示并继续填已扫到的字段，不中断整体流程。
- **填充动作**：复用 `runFill(false)`（只填勾选项），扫描后匹配项默认全勾选，故等价于填全部匹配项。
- **预览模式**：`fillAutoMode` 关闭时，主按钮只扫描 + 展开经历 + 展示预览列表，由用户勾选后点列表底部「填充勾选项（N）」。
- **空结果**：无匹配项且无手动项时 toast「未发现可填充字段」。

## 5. 结果列表减负

- 一键填充成功后，列表默认**只展示需人工处理的项**；已自动填充的成功项折叠在「已自动填充 N 项」内，点开可核对。
- 预览模式（自动填充开关关闭）下显示全部字段，便于逐项检查。
- 列表底部工具条：出现「填充勾选项（N）」按钮的条件为——
  - 预览模式下有勾选项；或
  - 用户取消勾选后仍有勾选项（部分补填）。
- 扫描结果行（`fillCurrentSite` 行）：末尾追加「清空」文字链接，点击后清空结果、取消失败项高亮（复用 `clearFill` 逻辑）。

## 6. 边界与降级

| 场景 | 行为 |
|---|---|
| 展开经历失败 | toast 提示，继续填已扫到的字段，不中断 |
| 扫描无字段 | toast「未检测到可填写的表单项」，回到初始态 |
| 填充中途失败字段 | 页面高亮失败项，列表「需人工处理」区展示，可补填后再次填充 |
| 自动填充开关关闭 | 主按钮 = 扫描 + 预览，不自动填充 |
| 无经历可展开 | 跳过展开步骤，直接匹配填充 |
| 新字段出现 | 照旧显示「继续填写（N）」 |
