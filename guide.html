猎投

从岗位页面到确认投递

首次：配置 AI → 创建简历 → 上传解析；日常：打开岗位 → 生成招呼语 → 一键投递。

01

配置 AI + 创建简历

在「设置」中填写 API 地址、模型和 Key，点击"测试连接"。你可以创建多份简历（如产品方向、AI 方向），每份独立管理内容和写作要求，投递时一键切换。

02

上传并解析简历

上传 JPG 或 PNG 简历图片，AI 会流式提取完整经历、项目、技能和量化成果。请检查提取结果并保存。简历内容会随招呼语发送时自动引用。

03

浏览岗位，加入清单

在 BOSS 职位列表或详情页，点击"加入投递清单"收集感兴趣的岗位。也可以点击"分析当前岗位"单独查看 JD 匹配结果并生成招呼语。

04

批量生成招呼语

在投递清单点击"批量生成招呼语"，AI 会针对每个岗位生成 3 条不同风格的招呼语。你可以点击风格标签切换，也可以直接在卡片中编辑修改。

05

开始投递

点击"开始投递"，插件会自动打开岗位详情、进入沟通页、发送简历图片和招呼语。成功后岗位会记入岗位库，可导出 CSV。投递过程中遇到连续失败会自动熔断保护账号。

发送前请确认岗位和招呼语。每次 AI 调用后会显示 Token 用量和费用估算，方便控制成本。如页面结构变化导致未能找到按钮，插件会提示你手动确认。
