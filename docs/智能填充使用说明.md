# 智能填充使用说明（v1.3.0）

智能填充是「猎投」的新增主功能：在第三方公司网申页面的信息录入页面，自动识别输入框、下拉框、单选框、复选框、文本域等表单项，结合你的简历内容自动匹配并一键填充，大幅减少招聘季海投时的重复填写。

## 一、工作原理

1. **扫描**：在网申页面点击「一键智能填充」，插件先识别页面上所有可填写的表单项（原生控件 + 常见组件库自定义控件，如 Ant Design / Element）。
2. **匹配**：综合字段标签、控件属性、上下文、类型和选项匹配简历字段；站点模板与 AI 结果也必须通过同一套本地校验。
3. **展开与预览**：页面存在“新增教育/实习/工作/项目/获奖/语言/游戏经历”时，一键流程会自动按简历条目数展开并重扫（失败不中断，只提示）；展开完成后高置信项自动填充，剩余「需人工处理」项保留在列表供确认补填。侧边栏可搜索简历字段、补录缺失值并勾选要填充的项。
4. **填充**：填充前校验扫描标签页、页面会话和字段指纹；DOM 结构变化或目标不唯一时停止写入并要求重扫。
5. **记忆**：模板只记忆“页面字段 → 简历字段”的语义映射，不保存姓名、手机号等具体填写值；每次填充记录到历史。

## 二、前置准备

1. 在「设置」中配置 AI API（可选，仅复杂字段匹配与简历字段提取需要）。
2. 在「设置 → 我的简历」中上传/粘贴简历内容，并在「智能填充 → 简历字段」中点击「重新提取简历字段」生成结构化字段；提取后可手动修正。
   - **教育 / 工作 / 实习 / 项目经历支持多条**：以卡片形式展示（摘要：时间 · 学校/公司/项目 · 岗位/角色），点击卡片标题可展开校对与编辑，右上「+ 添加」新增一条，「删除本条」移除；页面重复字段按条目索引绑定，不复用上一条经历的值。
   - 其余单点字段（基本信息 / 求职意向 / 工作经历 / 个人介绍 / 其他补充）采用**单行紧凑布局**（标签在左、输入在右），并默认**只显示已填写字段**，空字段折叠在「展开空字段（N）」按钮中，随时可展开补填；头部显示「已填 N / 共 M 项」便于掌握完成度。
3. 打开目标公司的网申 / 信息录入页面（非 BOSS 直聘）。

## 三、操作步骤

1. 打开网申页面 → 切换到侧边栏「智能填充」标签页。
2. 确认顶部选择的简历正确。
3. 点击「一键智能填充」：
   - 首次使用会弹出该网站的访问授权，请点击允许；
   - 插件会自动扫描、按需展开经历区块并重新扫描，然后填充高置信项；
   - 完成后列表只展示「需人工处理 N 项」，已自动填充的成功项折叠在「已自动填充 N 项」里可展开核对。
4. 处理「需人工处理」项：
   - 灰色「需手动」项可先确认简历字段；简历缺值时可在下一行直接补录，格式与选项校验通过后即可勾选；
   - 可修改已通过本地校验的建议值；填充前会再次检查格式和页面选项。
   - 勾选后点击列表下方的「填充勾选项（N）」补填；想全部重填可直接再次点击「一键智能填充」。
5. 若只想先预览不自动填充，可在下方关闭「自动填充高置信项」开关，此时「一键智能填充」只扫描并展示全量列表，由你勾选后点「填充勾选项（N）」。
6. 填充完成后，失败项会在页面高亮；处理完毕后点击站点行尾的「清空」可移除高亮并重置本次填充。

## 四、设置项

| 设置 | 说明 |
|---|---|
| 复杂字段使用 AI 匹配 | 仅把未识别字段的页面证据发送给 AI 做 fieldKey 分类，不发送简历字段值；AI 结果仍需通过本地校验，通用文本框缺少本地证据时只显示建议并要求人工确认。 |
| 自动记忆站点模板 | 按站点与表单指纹记忆语义映射，不保存具体填写值；切换简历后从当前简历重新取值。 |

## 五、支持的控件

- 文本类：`text`、`tel`、`email`、`number`、`url`、`textarea`
- 选择类：原生 `select`、radio 单选组、checkbox 勾选（仅明确布尔值时自动勾选）
- 日期类：`date` 原生控件、`.ant-picker` / `.el-date-editor` 自定义日期及日期范围 slot
- 自定义下拉：`.ant-select` / `.el-select`（通过 `aria-controls` 关联可见弹层，点击选项并回读）
- 复合手机号：区号与号码分槽；区号从手机号推导并选择，号码只写入主输入框
- 动态经历：一键流程自动识别新增按钮并按简历条目数展开，逐次验证 DOM 数量增长并重新扫描；展开失败不中断填充
- 不填充：密码、文件上传、隐藏控件（标记「需手动」）

## 六、常见问题

**为什么扫描不到表单项？**
页面表单可能为异步渲染或使用了 iframe / Shadow DOM，请等待页面加载完成后再扫描；v1 不支持 iframe 内部表单。

**为什么某字段显示「需手动」？**
简历中缺少对应信息、字段存在第三方联系人语义、重复经历条目无法自动确定、控件类型冲突，或扫描后页面结构已变化。可在侧边栏选择正确的简历字段；密码/文件仍需在页面手动处理。

**AI 匹配失败会影响填充吗？**
不会。AI 仅补全未识别字段，失败时自动降级，其余字段正常填充。

**隐私说明**
开启 AI 匹配时，仅表单字段标签、控件属性、选项和上下文会发送到你配置的 AI 服务，简历字段值不会用于字段匹配请求；「重新提取简历字段」会把简历文本发送给 AI 服务用于结构化提取。站点授权、语义映射模板与日志均保存在本机 Chrome 扩展存储中。
