### 3. 流畅度

- 字段间 100 ms 批处理间隔，逐字段回报进度，可中途取消；
- 无同步长任务；交互前仅对目标字段 scrollIntoView；
- 夹具环境填充 50+ 字段耗时在秒级以内。

## 三、修复记录

| 日期 | 问题 | 修复 |
|---|---|---|
| 2026-08-03 | 包裹 label 文本包含控件自身内容（select 选项文本混入标签） | 新增 labelTextOf 排除控件子树 |
| 2026-08-03 | radio 组标签误取选项文本（如「男」而非「性别」） | radio 组标签容器优先 + 前邻文本兜底 |
| 2026-08-03 | 自定义下拉（antd select）标签为空 | form-item 容器优先于控件容器提取标签 |
| 2026-08-03 | cleanText 误接收字符串导致标签提取为空 | 拆分为 cleanString / cleanText |
| 2026-08-03 | 工作经历行「至今」无独立「至」分隔符导致解析失败 | 时间区间正则兼容「至 / 至今 / - / —」 |
| 2026-08-03 | 匹配结果缺 label/type 字段（UI 与测试需要） | matchRules 补充 label/type |
| 2026-08-03 | 自定义下拉假成功（未展开/未回读校验，写 input 未提交也报成功） | 点击展开 + 1.5s 等待 + 容器展示值回读校验，无法确认如实报错；fillOne 改 async 并 await |
| 2026-08-03 | radio 非首选项误报「回读校验失败」 | 回读校验改为检查实际点击的目标选项 |
| 2026-08-03 | select 选项 value≠label 时必失败 | 按选项文本模糊匹配选中并设值 |
| 2026-08-03 | hidden/追踪字段污染扫描列表 | hidden 与不可见控件不再输出 |
| 2026-08-03 | SMART_FILL_PROGRESS 死代码 | 消息路径接入 onProgress 并发送进度事件 |
| 2026-08-03 | 失败填充值被写入站点模板 | 模板仅收录填充成功或成功且被修正的字段 |
| 2026-08-03 | 分步表单模板覆盖丢失历史字段 | saveTemplateFromResults 合并更新、历史字段保留追加 |
| 2026-08-03 | 原生 select 无选项信息导致匹配器不校验选项 | 扫描收集 select 选项，匹配器校验选项（含子串合理匹配） |

| 2026-08-03 | 识别/填写错位：扫描缓存元素引用在页面重渲染后失效（值写进脱离文档的旧节点）；容器标签被复用到同一容器内多个控件（多个字段填同一值） | 填充前按 path 选择器重新解析元素（radio 组按 name 重查）；非 radio 控件仅在容器内控件唯一时采用容器标签；新增重渲染定位与标签不串用回归测试 |
