# 猎投 — BOSS 直聘 AI 投递助手

Chrome 扩展。自动读取 BOSS 直聘岗位信息，用 AI 对比你的简历生成个性化招呼语，支持批量投递。

## 功能特性

- **自动读取岗位**：打开 BOSS 职位列表或详情页，插件自动抓取岗位名称、公司、薪资、完整 JD
- **多份简历管理**：支持创建最多 5 份简历（如产品方向、AI 方向），每份独立管理内容和写作要求
- **AI 招呼语生成**：3 种风格（直接匹配型 / 项目证据型 / 自然沟通型），可切换挑选
- **流式简历解析**：上传简历图片，AI 实时提取完整内容
- **批量投递**：加入清单 → 批量生成招呼语 → 一键投递，自动熔断保护账号
- **Token 用量显示**：每次 AI 调用后显示消耗和费用估算
- **岗位库与导出**：投递记录自动归档，支持导出 Excel 兼容 CSV

## 安装

1. 下载项目代码
2. 打开 Chrome，访问 `chrome://extensions`
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展程序"，选择本项目文件夹
5. 点击工具栏猎投图标，侧边栏打开即可使用

## 使用流程

1. **配置 AI**：在设置中填写 API 地址、模型和 API Key（支持 OpenAI 兼容接口），点击"测试连接"
2. **上传简历**：上传 JPG/PNG 简历图片，AI 流式提取完整内容，检查并保存
3. **浏览岗位**：打开 BOSS 职位详情或列表页，点击"加入投递清单"收集岗位
4. **生成招呼语**：点击"批量生成招呼语"，AI 生成 3 种风格，可切换挑选或直接编辑
5. **开始投递**：点击"开始投递"，自动完成批量发送。Token 用量实时显示，连续失败自动熔断
6. **查看记录**：成功投递的岗位记入岗位库，可导出 CSV

## 技术栈

- Chrome Manifest V3
- ES Modules（无框架依赖）
- OpenAI 兼容 API
- Rollup 打包

## 开发

```bash
npm install        # 安装依赖
npm run check      # 语法检查
npm test           # 运行测试（75 个单元测试）
npm run build      # 生产构建
npm run dev        # 开发模式（watch）
```

## 隐私说明

- 简历图片、简历全文和岗位 JD 仅发送到你配置的 AI 服务地址
- API Key 以明文保存在本机 Chrome 扩展存储中
- 所有数据均存储于本地，不上传到任何第三方服务器
- 建议使用可随时废止的低额度 API Key
- AI 服务地址强制要求 HTTPS，拒绝本地/内网地址
